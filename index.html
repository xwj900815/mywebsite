01 — Platform

Six families, one data model.

Every product shares the same data model, the same services and the same security boundary, so a project can start on a laptop and finish in a cloud cluster without a migration.

P-01 Desktop GIS 2D and 3D editing, mapping, output, visualisation and analysis — MapGIS Desktop, 3D SceneBuilder and 3D GeoModeler.
P-02 Server GIS Full GIS services plus publishing, management, monitoring and security in one resource manager — MapGIS IGServer.
P-03 Cloud GIS Storage, servers, operations and applications for cloud deployments, plus the CIM basic platform for city information models.
P-04 Digital Twin Landscape, BIM, photogrammetry, point cloud, geological bodies and pipelines fused into one scene — MapGIS TwinWorld.
P-05 Mobile GIS Field collection, editing, analysis and navigation on mobile devices — MapGIS Mobile Collector and Mobile Explorer.
P-06 Development Desktop components and SDK, JavaScript and WebGL clients, mobile SDK — the building blocks for your own GIS products.
02 — Technology

Five pillars under the stack.

What MapGIS 10.7 actually brings to a project: an adaptable kernel, a full-space 3D model, a big-data pipeline, embedded intelligence, and a single toolchain for every terminal.

Cross-platform One kernel, many machines

Runs across a broad range of CPUs and operating systems, and scales up across the whole product line.

Full-space 3D Above and below the surface

The M3D format fuses landscape, BIM, photogrammetry, point cloud and geology into one scene.

Big data Collect to insight

A collect–store–manage–compute–use pipeline for spatiotemporal data, from ingestion through analysis.

Intelligent From sensing to reasoning

AI and large-model integration that turns map data into decisions for agencies and utilities.

Full stack Build once, run anywhere

Agile tooling for multi-terminal applications, so teams build the product instead of the plumbing.
